# games-pokemon

Projeto de jogo interativo sobre Pokémon, com desafios de adivinhação e filtros por características do personagem. A aplicação foi desenvolvida para proporcionar uma experiência divertida e educativa, permitindo que o usuário teste seu conhecimento sobre espécies, evoluções e atributos.

## Tecnologias

- React
- Vite
- JavaScript
- CSS
- PokeAPI

## Objetivo

1. Explorar e adivinhar Pokémon por imagem, nome, geração e outras informações, usando a API oficial do Pokémon para buscar dados em tempo real.
